# Escala de Pregação

Site de consulta da escala de pregação e avisos. A página `index.html` é autônoma: os dados da escala ficam embutidos nela e ela abre em modo de consulta, sem login.

Para publicar com GitHub Pages: **Settings → Pages**, branch `main`, pasta `/ (root)`.

A edição da escala é feita no site original; depois o `index.html` é atualizado aqui.
